# note採用広報 徹底活用セミナー LP

## 公開方法（GitHub Pages）
1. GitHubで新規の **Public** リポジトリを作成します。
2. このZIPをPCで解凍します。
3. 解凍したフォルダの中にある **index.html / style.css / script.js / 01.png〜07.png** を、すべてリポジトリの最上位にアップロードします。**フォルダを1つ挟まない**でください。
4. GitHubリポジトリの **Settings → Pages** を開き、**Build and deployment → Deploy from a branch → main / (root) → Save** を指定します。
5. 公開URLは通常 `https://sketch-consulting-lp.github.io/リポジトリ名/` となります。
